# Ribbon UI Studio v4.0.1

Ribbon UI Studio v4.0.1 is a maintenance release focused on the software license agreement.

## What's new

- Added the **End User License Agreement (EULA)** to the application/distribution flow.
- The EULA is now presented as part of the software licensing terms for Ribbon UI Studio.

## Changes from v4.0.0

No new editor features or workflow changes are introduced in this release. The application functionality remains the same as v4.0.0; this update only adds the EULA/license agreement.

## Download

Official Windows binaries for this release should be attached to the GitHub release:

- `Ribbon.UI.Studio-Setup.exe`
- `Ribbon.UI.Studio_Portable.exe`
- `Ribbon_UI_Studio-Setup.msi`
- `Ribbon_UI_Studio_Bundle.exe`

For Office add-in deployment, InstallerLab remains a separate required application when generating EXE, MSI or Bundle packages.

InstallerLab: https://installerlab.website/
